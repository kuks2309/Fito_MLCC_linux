# Halcon Blob 방식 Index 검출 Flowchart

## HV_FindFirstMarkCenter (Halcon Blob 방식 Index 검출)

```
┌─────────────────────────────────────────────────────────────────┐
│                    HV_FindFirstMarkCenter                        │
│                   (Halcon Blob 방식 Index 검출)                   │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 1: 이미지 전처리 (HV_ImgProcess_Prepare)                    │
│   - 입력 이미지 → 이진화 Region 생성                              │
│   - DL 모드: DLProcess() → HV_ImgProcess_Prepare_DL()           │
│   - 일반 모드: HV_ImgProcess_Prepare()                           │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 2: 커버 제거 (bUseRemoveCover == true 일 때)                │
│                                                                 │
│   Halcon 원본 코드:                                              │
│   ClosingCircle(ho_OrgRegion, &LongRegion, 20.5);               │
│   OpeningRectangle1(LongRegion, &LongRegion, 10, iFilterSize);  │
│   DilationCircle(LongRegion, &LongRegion, 20.5);                │
│   Difference(ho_OrgRegion, LongRegion, &diffRegion);            │
│   OpeningCircle(diffRegion, &ho_OrgRegion, 6.6);                │
│                                                                 │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 2-1. ClosingCircle(ho_OrgRegion, &LongRegion, 20.5)      │  │
│   │      → 원본(ho_OrgRegion)에 Closing → LongRegion 생성     │  │
│   │      → 작은 구멍 메우기                                    │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 2-2. OpeningRectangle1(LongRegion, &LongRegion, 10, H)   │  │
│   │      → LongRegion에 Opening → LongRegion 갱신             │  │
│   │      → 세로로 긴 구조(커버) 추출                            │  │
│   │      → iFilterSize = Index높이 × 4                        │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 2-3. DilationCircle(LongRegion, &LongRegion, 20.5)       │  │
│   │      → LongRegion 확장 → LongRegion 갱신                  │  │
│   │      → 커버 영역 확장                                      │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 2-4. Difference(ho_OrgRegion, LongRegion, &diffRegion)   │  │
│   │      → 원본(ho_OrgRegion) - LongRegion = diffRegion      │  │
│   │      → 원본에서 커버 빼기 (중요: closed가 아닌 원본!)       │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 2-5. OpeningCircle(diffRegion, &ho_OrgRegion, 6.6)       │  │
│   │      → 노이즈 제거 → 최종 결과                             │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 3: Projection 기반 분리                                     │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 3-1. RegionToBin() → 이진 이미지 생성                      │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 3-2. GrayProjections(simple, hv_hor)                     │  │
│   │      → 수평 방향 프로젝션 계산                              │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 3-3. Threshold(hv_Max × 0.5)                             │  │
│   │      → 프로젝션 임계값 적용                                 │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 3-4. Connection() → 프로젝션 영역 분리                     │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 4: 연결 성분 분석 및 필터링                                  │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 4-1. Connection(ho_Region)                               │  │
│   │      → 연결된 영역 분리                                    │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 4-2. SelectShape(width, WMin ~ WMax)                     │  │
│   │      WMin = Index폭 × 0.5, WMax = Index폭 × 2.0          │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 4-3. SelectShape(height, HMin ~ HMax)                    │  │
│   │      HMin = Index높이 × 0.5, HMax = Index높이 × 3.0      │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ 4-4. AreaCenter() → 각 Blob의 면적, 중심 좌표 계산         │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 5: Y좌표 정렬                                               │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ nFirstMarkFindType == _OUTSIDE (상단 Index 찾기)          │  │
│   │   → SorttoMinValueY() : Y 오름차순 (상단부터)              │  │
│   ├──────────────────────────────────────────────────────────┤  │
│   │ nFirstMarkFindType == _INSIDE (하단 Index 찾기)           │  │
│   │   → SorttoMaxValueY() : Y 내림차순 (하단부터)              │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 6: Index Pitch 검증 (핵심 로직)                             │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ dIndexPitch = 설정된 Index 간격                           │  │
│   │ dPitchTol = dIndexPitch / 3.0  (허용 오차 33%)            │  │
│   └──────────────────────────────────────────────────────────┘  │
│                          │                                       │
│                          ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ for k = 0 to (검출수 - 1):                                │  │
│   │   actualPitch = |fp[k].y - fp[k+1].y| × dCalValue         │  │
│   │                                                          │  │
│   │   if (dIndexPitch - dPitchTol) < actualPitch              │  │
│   │      < (dIndexPitch + dPitchTol):                         │  │
│   │       → nFindIndex = k                                    │  │
│   │       → bFindRet = true                                   │  │
│   │       → break                                             │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 7: 첫 번째 유효 Index 결정                                  │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │ if (검출수 == 1):                                         │  │
│   │   → 첫 번째 Index 사용                                    │  │
│   ├──────────────────────────────────────────────────────────┤  │
│   │ else if (검출수 == 2 && Pitch 불일치):                    │  │
│   │   → 두 번째 Index 사용                                    │  │
│   ├──────────────────────────────────────────────────────────┤  │
│   │ else:                                                     │  │
│   │   → Pitch 일치하는 첫 번째 Index 사용 (nFindIndex)        │  │
│   └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 8: 결과 반환                                                │
│   - stResult.dPositionX = 첫 번째 유효 Index의 X 좌표           │
│   - stResult.dPositionY = 첫 번째 유효 Index의 Y 좌표           │
│   - stResult.bResult = true                                     │
└─────────────────────────────────────────────────────────────────┘
```

## 이미지 전처리 모드 비교

### 일반 모드: HV_ImgProcess_Prepare()

```
입력 이미지 (Grayscale)
        │
        ▼
┌───────────────────────────────────────┐
│ Threshold (이진화)                     │
│   - 고정 임계값 또는 자동 임계값 사용    │
│   - 밝은 영역 = 255, 어두운 영역 = 0   │
└───────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────┐
│ Morphology (형태학 연산)               │
│   - Opening: 노이즈 제거               │
│   - Closing: 작은 구멍 메우기          │
└───────────────────────────────────────┘
        │
        ▼
    이진 Region 출력
```

**특징:**
- 단순 임계값 기반 이진화
- 빠른 처리 속도 (~1ms)
- 조명 변화에 민감

### DL 모드: HV_ImgProcess_Prepare_DL()

```
입력 이미지 (Grayscale)
        │
        ▼
┌───────────────────────────────────────┐
│ DLProcess() - Deep Learning 추론       │
│   - 사전 학습된 모델로 세그멘테이션      │
│   - 픽셀 단위 분류 (Index vs Background)│
└───────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────┐
│ DL 출력 → Region 변환                  │
│   - 확률 맵 → 이진 마스크              │
│   - confidence threshold 적용          │
└───────────────────────────────────────┘
        │
        ▼
    이진 Region 출력
```

**특징:**
- AI 기반 세그멘테이션
- 조명/노이즈에 강건함
- 느린 처리 속도 (~10-50ms, GPU 필요)

### 비교표

| 항목 | 일반 모드 | DL 모드 |
|------|----------|---------|
| 방법 | 임계값 이진화 | Deep Learning |
| 속도 | 빠름 (~1ms) | 느림 (~10-50ms) |
| 조명 변화 | 민감 | 강건 |
| 설정 | 임계값 튜닝 필요 | 모델 학습 필요 |
| 정확도 | 환경 의존적 | 일반적으로 높음 |

## OpenCV 구현 매핑

| Halcon 함수 | OpenCV 함수 |
|-------------|-------------|
| `Threshold` | `cv2.threshold()` |
| `ClosingCircle` | `cv2.morphologyEx(MORPH_CLOSE)` |
| `OpeningRectangle1` | `cv2.morphologyEx(MORPH_OPEN)` |
| `DilationCircle` | `cv2.dilate()` |
| `Difference` | `cv2.subtract()` |
| `Connection` | `cv2.connectedComponentsWithStats()` |
| `SelectShape` | 수동 필터링 (area, width, height) |
| `AreaCenter` | `connectedComponentsWithStats` 출력 사용 |
| `GrayProjections` | `np.sum(axis=1)` |

## 파라미터 설명

| 파라미터 | 설명 | 기본값 |
|----------|------|--------|
| `threshold_value` | 이진화 임계값 | 40 |
| `min_area` | 최소 Blob 면적 | 3000 |
| `max_area` | 최대 Blob 면적 | 100000 |
| `cover_filter_size` | 커버 제거용 Opening 높이 | 400 |
| `index_pitch` | Index 간격 (픽셀) | 500 |
| `pitch_tolerance` | Pitch 허용 오차 | 33% |
